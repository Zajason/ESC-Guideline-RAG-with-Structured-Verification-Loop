# Security and Responsible Disclosure

This project handles workflows that may involve sensitive clinical data in private research settings.

## Reporting

If you find a security or privacy issue, please open a private disclosure through GitHub security advisories if available, or contact the repository owner directly.

## Sensitive Data

Never publish:

- patient identifiers
- original clinical documents
- full research workbooks with patient rows
- raw model logs from patient cases
- API keys

## Intended Use

This repository is for research and benchmarking only. It is not intended for clinical decision support.
